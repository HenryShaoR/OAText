# The repo combines the following:
- https://github.com/jfang4w/frontend (./client)
- https://github.com/jfang4w/backend (./server)

# Steps to use:
- Run `./init.bat` or `./init.sh` to install all required dependencies,
- Run `./start.bat` or `./start.sh` to start the server and client,
- Open `http://localhost:5173/login` (or other assigned port),
- Wait until the server connects to the database,
- Continue on the browser.
