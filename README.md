# The repo combines the following:
- https://github.com/jfang4w/frontend (./client)
- https://github.com/jfang4w/backend (./server)

# Steps to use:
1. Run `make -j2` to install dependencies and start both frontend and backend,
2. Open `http://localhost:5173/login` (or other assigned port), 
3. Wait until the server connects to the database, 
4. Continue on the browser.
